# Learning Modern JavaScript (ES6+)

A collection of hands-on JavaScript examples exploring modern language features, asynchronous programming, and fundamental programming concepts.

## Concepts Covered

- `let` and `const`
- Arrow functions
- Template literals
- Default parameters
- Rest and spread syntax
- Array and object destructuring
- Promises and Promise chaining
- Async/await and Fetch API
- Error handling with try/catch

## Technologies Used

- JavaScript (ES6+)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/SagnikaGoswami/Learn-ES6-JavaScript.git
   ```
2. Open the project folder.
3. Run `script.js` using Node.js:
   ```bash
   node script.js
   ```

Some asynchronous examples are commented out and can be explored individually.
